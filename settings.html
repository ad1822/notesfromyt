YouTube Summarizer

Configure API keys to enable summarization and transcript fetching.

Where to Get API Keys

Gemini API: Get it from https://aistudio.google.com/api-keys
YouTube Transcript API: Visit https://www.youtube-transcript.io and generate your key.

How This Extension Works

1. Opens a YouTube video.
2. Fetches the transcript automatically.
3. Summarizes the transcript using Gemini.
4. Saves both transcript and summary locally for offline access.

Storage Locations

Notes → ~/Downloads/notesfromyt/Video Title/Video Title.md
Screenshots → ~/Downloads/notesfromyt/Video Title/screenshot/screenshot-date-time.png
